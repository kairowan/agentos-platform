# Security Policy

AgentOS is experimental and must not yet be used as a daily-driver or trusted with
sensitive data.

Please report vulnerabilities privately through GitHub's private vulnerability
reporting feature instead of opening a public issue. Include the affected commit,
reproduction steps, impact, and any suggested mitigation.

The project treats model output, downloaded content, generated workflows, and
external tool results as untrusted input. A report that demonstrates bypassing the
capability registry, user confirmation, process isolation, or data scope is a
security vulnerability.
